# Fonts

These fonts are embedded in the firmware. Both are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org), which allows bundling and redistribution
with software as long as the fonts are not sold on their own.

| Font | Designer | Source |
|---|---|---|
| Averia Serif Libre (Regular, Bold, Italic, Bold Italic) | Dan Sayers | https://fonts.google.com/specimen/Averia+Serif+Libre |
| Quicksand (Regular, Bold) | Andrew Paglinawan | https://fonts.google.com/specimen/Quicksand |

The full licence text for each family is on its Google Fonts page and in the
[google/fonts](https://github.com/google/fonts/tree/main/ofl) repository.
